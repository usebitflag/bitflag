# BitFlag

BitFlag core: the Laravel application (backend, Inertia/Vue portal, management API, SDK delivery, workers) and the Filament admin console for the hosted BitFlag feature flag service.

Technical documentation is in [docs](docs/README.md).

Related repositories (planned): `bitflag-protocol`, `bitflag-php`, `bitflag-js`.

## Development

The application runs in Docker through Laravel Sail. Only Docker and Git are required on the host. See [local development](docs/development.md) for the first-run steps, services and ports.
