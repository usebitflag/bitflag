# BitFlag

BitFlag core: the Laravel application (backend, Inertia/Vue portal, management API, SDK delivery, workers) and the Filament admin console for the hosted BitFlag feature flag service.

Design documentation and milestone plans are in [docs](docs/README.md). Work starts with [M0 Foundations](docs/milestones/M0-foundations.md).

Related repositories (planned): `bitflag-protocol`, `bitflag-php`, `bitflag-js`.
